# Responsive-Developer-Portfolio

A clean, modern, and mobile-responsive personal portfolio website built without the use of external CSS frameworks like Bootstrap or Tailwind. It utilizes CSS Flexbox and semantic HTML to showcase projects, skills, and contact information.

Features

Mobile-First Design: Fully responsive layout that adapts to desktops, tablets, and mobile devices.

Modern UI/UX: Clean typography, intuitive navigation, and a high-contrast dark mode theme.

Flexbox Layout: Efficiently structures the navigation bar, hero section, and skills grid.

Tech Stack

HTML5: Semantic markup for better accessibility and SEO.

CSS3: Custom styling, Flexbox layout, and media queries for responsiveness.

How to Run Locally

Clone this repository: git clone https://github.com/JMAGUSTIN01/developer-portfolio.git

Navigate to the project folder.

Double-click the index.html file to open it in your preferred web browser.
