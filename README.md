# Responsive Developer Portfolio
A mobile-first personal portfolio webpage designed to showcase development skills, projects, and contact information.

## Features
* **Responsive Design**: Adapts seamlessly to desktop, tablet, and mobile screens.
* **Modern UI**: Dark mode aesthetic with clean typography and CSS Flexbox layouts.
* **No Dependencies**: Built entirely with plain HTML5 and CSS3 without relying on bulky frameworks.

## How to Run
Simply open `index.html` in any web browser.
